# Run without code

1. Open the [hosted Actor](https://apify.com/datascraperes/zillow-property-detail-scraper?fpr=edudata) and sign in.
2. Keep the example property URL and maxResults at 1 for a small first run.
3. Review the current Pricing tab and run spending limit, then select Start.
4. Inspect run status, Dataset rows and the SUMMARY record in key-value storage.
5. Export JSON, CSV or Excel from the Dataset. Missing source information stays unavailable.

After that, replace the URL with known properties, exact addresses, or a search-results Dataset ID. Building expansion can increase the number of records; start with extractBuildingUnits disabled.
