# Workflows

## Known-property enrichment

Use listing URLs or exact addresses to retrieve available facts and estimates for a selected set of properties. Ambiguous address matches are reported rather than silently replaced.

## Search Dataset to detailed records

Pass an existing Dataset ID containing propertyUrl, url, detailUrl or a positive ZPID. The Actor deduplicates properties within the run. This imports identifiers; it does not discover an entire market.

## Export after collection

Download a completed Dataset repeatedly without starting another Actor run. Use JSON for nested history and photo information; CSV exports in this repository serialize nested cells as JSON.

Building records and optional unit expansion depend on available inventory. Community expansion is bounded and is not a guarantee of complete community coverage.
